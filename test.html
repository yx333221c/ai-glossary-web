✅ AI 术语词典已创建成功!

📂 项目文件:

  • index.html - 主页面
  • styles.css - 样式表
  • app.js - JavaScript 逻辑
  • README.md - 项目说明
  • .gitignore - Git 忽略配置

🎯 功能特性:

  • ✅ 智能搜索: 支持中英文关键词搜索，按匹配度排序
  • ✅ 完整术语库: 60+ AI 核心术语，包括：
    • 数学基础：Token、Embedding、KL Divergence、梯度、学习率等
    • 神经网络：Backpropagation、CNN、Transformer 等
    • 注意力机制：Attention、Query/Key/Value、Self-Attention 等
    • 训练方法：Pretraining、Fine-tuning、RLHF、Alignment 等
    • 推理生成：Hallucination、Temperature、Sampling 等
    • 多模态：CLIP、Multimodal、Vision-Language 等
    • 进阶主题：Agent、RAG、Prompt Engineering 等
  • ✅ 响应式设计: 完美适配桌面端、平板、移动端
  • ✅ 精美界面: 紫色渐变主题，卡片式布局，交互流畅
  • ✅ 相关术语: 每个词条显示关联概念，便于深入学习

🚀 使用方法:

  1. 直接在浏览器中打开 index.html
  2. 在搜索框输入关键词（如 "attention" 或 "注意力"）
  3. 查看按匹配程度排序的相关术语
  4. 点击任意术语查看详情和定义

🔧 技术栈:

HTML5 + CSS3 (Flexbox/Grid) + Vanilla JavaScript (ES6+) — 无框架依赖，轻量快速
